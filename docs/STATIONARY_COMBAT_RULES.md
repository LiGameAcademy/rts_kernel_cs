# 固定站位战斗：纯规则第一批

本批仅提供Combat目录内的数值规则，还没有攻击状态机、命令、死亡、聚合快照或Godot接入。现有移动实现、事件与v14存档没有改动。

- WeaponDefinition / CombatDefinition是只读配置，公开入口再次Validate，record的with不能绕过校验。
- CombatTiming将定点秒向上取整为逻辑帧。上限3600秒，TickRate为1–240；运行时应保存绝对帧截止时间。
- CombatDice使用调用方对局独占的DeterministicRng，骰子为闭区间[1,Sides]，拒绝采样避免模偏；合法出手才调用。零骰不消耗随机，查询与伤害计算不推进随机流。
- CombatDamageRules保留本项目7×7攻防倍率及护甲公式，返回只读计算结果，不直接扣血。它不代表原作所有版本或英雄、Buff、技能的伤害规则。

伤害顺序：基础伤害+骰子 → 攻防倍率 → 护甲 → 正伤不足1取1。护甲系数按1-(0.06×armor)/(1+0.06×abs(armor))计算。0.06及倍率由分数转32.32，逐次乘除向零截断；因此结果与旧double存在细微差异。零及已截成零的极小伤害不触发最低伤害。比如160伤害、10护甲得到100+480/2^32，而不是精确100；-10护甲得到220-480/2^32。

输入域：基础伤害0–1,000,000；骰数0–64；骰面1–1,000,000；生命(0,1,000,000,000]；护甲±1,000,000；射程0–1,000,000且最小不大于最大；冷却1–864,000帧且前摇0–冷却。最大掷骰结果65,000,000，乘最大倍率2和小于2的护甲系数后仍在32.32域内。未知类型及越界配置明确拒绝，不静默回退。

验证：`dotnet run --project tests/Rts.Kernel.Tests -c Release -- --combat-rules`；完整回归入口仍为`./Test.ps1`。功能检查通过不等于现有移动或完整战斗性能通过。
