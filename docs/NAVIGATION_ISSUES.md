## 1. 在纯 C# 内核中实现可重复的静态网格寻路

当前 PathingGrid 只能读取阻挡，无法查询绕开障碍的路径。本批对应 R02.2 静态路径查询，采用同步八邻接 A*，沿用游戏现有 Octile 代价和禁止斜穿墙角规则。固定邻居遍历与同代价排序，不使用墙钟预算。仅实现静态地面点单位；不代表尺寸净空、真实移动或完整 R02.2 已完成。

验收：明确返回成功、非法端点、不可达及搜索节点上限；覆盖同格、边界、绕墙和角落阻挡；重复与交错调用一致；用独立最短路算法核对代价；保留快照、实例隔离和 CLI 回归。公开 API 改动按复杂项保留 PR，由用户验收后合并。

本地分支：codex/kernel-static-pathfinding。当前实现 GridPathfinder.FindPath，返回含起终格的只读路径。Cost 单位为网格步长，直线 1、对角 1.4142135；不是世界距离。非成功结果路径为空、代价为正无穷。maxExpandedNodes 计数包括起点与终点，耗尽返回 NodeLimitReached，搜索穷尽返回 Unreachable。阻挡端点直接拒绝，宿主的目标吸附留到后续批次。每次调用独立分配搜索状态。

验证：.NET 10 SDK，Release 构建零警告/错误；903 项断言通过（包括原 53 项）。全部 512 种 3×3 障碍布局与独立 Dijkstra 参考比较，并核对路径合法性、代价和交错查询。CLI 原状态哈希一致。

## 2. 支持单位尺寸净空与对局独占的动态障碍

依赖第 1 项。当前静态点单位路径不能满足建筑占地和大单位通行。明确静态阻挡与动态占地的合并规则、单位尺寸参数及障碍更新入口。由对局持有可变障碍，地图静态定义仍只读共享。动态状态进入快照和校验，更新后的路径查询只使用当前逻辑帧状态。

验收：窄路/大单位、重叠占地添加移除、边界、两个对局隔离、恢复后路径结果一致。用测试命令更新障碍，暂不迁移完整建造系统；不依赖 Godot。净空定义与现有游戏对照记录。

## 3. 让移动命令沿内核路径推进，并接入 Godot 隔离场景

依赖前两项。迁移目标订单、路径进度、停止和替换，按固定帧推进，位置写入由内核独占；Godot 消费只读位置与事件。按现有规则逐步接入转向、坡度、预约和避让，保持可分批验收，不同时保留两个权威移动入口。

验收：绕墙移动、停止/替换、不可达、动态障碍、移动中快照恢复、交错对局；CLI 与 Godot 相同输入逐帧校验一致。选择、模型动画及画面插值在宿主。300/500 性能基线和 Windows 导出仍按已确认暂缓，不宣称达标。该项涉及真实游戏手感，保留 PR 待用户测试。
